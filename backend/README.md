AOM Secure: AI-Powered Banking MiddlewareAOM Secure is a high-performance banking backend built with FastAPI. It serves as the orchestration layer between the Squad (GTCO) Payment API, a React-native frontend, and a Hybrid Temporal Graph Transformer (TGT) AI Engine.By acting as a "Security Intercept," this backend ensures that no Naira leaves the ecosystem unless it has been mathematically cleared by our 5-model deep learning ensemble.🚀 System ArchitectureThis backend (Port 8000) operates as the central hub:The Gatekeeper: Ingests transaction requests from the mobile/web client.The Analyst: Forwards behavioral data and payloads to the TGT AI Engine (Port 8080).The Executor: Triggers the Squad API for Virtual Account creation and Payouts only upon AI clearance.The Ledger: Maintains a local SQLite state for sub-millisecond balance polling.🛠️ FeaturesSquad Virtual Accounts: Automated generation of GTCO-backed virtual accounts for users.AI-Verified Payouts: Real-time interception of /payout/transfer calls to prevent social engineering and SIM swap fraud.Dispute Auto-Trigger: Immediate calls to Squad’s /dispute endpoint to freeze funds when the AI detects a "Red Zone" (Risk > 0.90) attempt.Real-time Polling: Optimized endpoints for frontend balance sync and transaction toasts.🔌 Core API Endpoints1.
